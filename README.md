# Offer Letter Generator

A web application for generating professional offer letters from structured information.

## Features
- Offer-letter generation workflow
- Browser-based interface
- Reusable document-generation experience
- Build output included in `dist/`

## Tech Stack
- HTML5
- JavaScript
- Node.js/npm tooling

## Getting Started
Clone the repository, install dependencies and use the scripts defined in `package.json`.

```bash
npm install
```

Then run the appropriate development/build command from `package.json`.

## Use Cases
- HR prototypes
- Small-business hiring workflows
- Generating consistent employment-offer documents

## Status
Active prototype. Production deployments should add proper validation, authentication and secure handling of employee information.
